# workshop-prototype

ריפו פתיחה לסדנת Claude ו-Claude Code של סטודיו UX/UI באמן דיגיטל.
בונים כאן אב-טיפוס לאפליקציית חיסכון לבני נוער. הלקוח בדוי, והנתונים נתוני דמה בלבד.

## מה יש כאן

| תיקייה / קובץ | מה זה |
| --- | --- |
| `CLAUDE.md` | הכללים הקבועים של הפרויקט. Claude קורא אותו בתחילת כל שיחה |
| `brief/client-brief.md` | הבריף של הלקוח |
| `design-system/` | ריק בכוונה. בתרגיל הראשון שולפים לכאן את מערכת העיצוב מפיגמה |
| `assets/` | לוגו, אייקונים ותמונות |
| `references/` | צילומי מסך של המסכים מפיגמה, להשוואה |
| `.claude/skills/rtl-prototype/` | סקיל: איך בונים אב-טיפוס בעברית בסטודיו |
| `.claude/agents/design-reviewer.md` | סוכן שבודק כל מסך מול הבריף ומערכת העיצוב |
| `src/` | הקוד. Claude יוצר ומנהל אותו |

## איך מתחילים

1. פותחים את התיקייה בלשונית Code באפליקציית Claude Desktop.
2. כותבים: "תתקין את מה שצריך ותריץ את הפרויקט". נפתח דפדפן עם מסך פתיחה.
3. מתחילים מהתרגיל הראשון: "תשלוף את המשתנים והקומפוננטות מקובץ הפיגמה הזה לתיקייה design-system" ומדביקים את הקישור.

קובץ הפיגמה של התרגיל: https://www.figma.com/design/o47r5B4SktmRMFDx3LkAa1
