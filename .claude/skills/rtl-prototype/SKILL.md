description: Use when building or editing any Hebrew UI screen or component in this prototype.
---

1. Read CLAUDE.md and brief/client-brief.md if you have not in this session.
2. Use only tokens from design-system/tokens.css and components described in design-system/components.md.
3. Layout is RTL: start-aligned means right. Use logical CSS properties (margin-inline-start, padding-inline-end) instead of left/right.
4. Mobile first at 390px. Check the screen also looks right at 360px.
5. Use the dummy data from the brief, never invent new names or amounts.
6. Show a short plan first. After building, run the app and compare to the matching image in references/ if one exists.
