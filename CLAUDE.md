# Project: youth savings app prototype (studio workshop)

Clickable prototype for a fictional client. Dummy data only, no backend.

## Language & layout
- Hebrew first: `<html lang="he" dir="rtl">`, mobile first, 390px wide
- Read brief/client-brief.md before building any screen
- Stay inside the brief's scope. "Not in scope" means do not build it

## Design system
- Source of truth: the Figma file https://www.figma.com/design/o47r5B4SktmRMFDx3LkAa1
- Tokens live in design-system/tokens.css; never hardcode colors, sizes or radii
- Read design-system/components.md before building a component
- Missing something from the system? Ask, don't invent it

## Stack
- React + Vite, no backend. Ask before adding any library

## Way of working
- One screen per task
- Show a plan before writing code
- After a screen works, suggest a git commit
